# TestFlight 1.2.1 (130)

Сборка доступна внутренней группе Beta Tester. Apple: VALID / IN_BETA_TESTING. Описание проверки сохранено на украинском, немецком и английском. Публичный релиз App Store не изменён.

## Что проверить

1. Владелец: Профиль → Сезонное оформление. Добавить Хеллоуин, проверить светлый и тёмный предпросмотр, название, разделы, интенсивность и реакцию на наклон.
2. Проверить даты начала/окончания, часовой пояс и ежегодное повторение. Для проверки сейчас выбранный период должен включать текущее время, тема должна быть включена.
3. Сохранить библиотеку: это не включает оформление у пользователей. Отдельно подтвердить публикацию, только если хотите включить оформление для всех пользователей новой сборки.
4. Проверить главные вкладки: тыкву, паутину, летучую мышь, наклон телефона, читаемость текста и доступность кнопок. При открытии вложенных окон и форм оформление не должно мешать.
5. Проверить возвращение из фона, слабую сеть, светлую/тёмную темы, «Уменьшение движения», энергосбережение. В настройках приложения выключить и снова включить сезонные эффекты.
6. Проверить «Выключить для всех»: опубликованное оформление исчезает, сохранённая библиотека остаётся для повторного использования.

Первичная физическая проверка внешнего вида, движения и плавности на iPhone ещё предстоит. Сезонная тема на сервере не активирована.
