# UAC 1.3 (155): совместимость с Mac

Сборка 155 исправляет закрытия UAC при переходах между разделами профиля на Mac с Apple silicon. Используется существующее iPhone/iPad-приложение, тот же аккаунт и те же серверные права. Отдельная платформа macOS/Catalyst и поддержка Intel в эту работу не входят.

В сборке 154 воспроизведено падение на Mac. Два из пяти отчётов прямо указывают на CoreMotion; три других содержат сбой освобождения фонового обработчика, их общая причина отдельно не доказана. В исправлении менеджер датчиков вообще не создаётся на Mac, а на iPhone создаётся только при необходимости. Обычные анимации сохранены.

Сборка 154 добровольно снята нами с рассмотрения Apple. Статус Developer Rejected здесь означает отзыв разработчиком, а не отказ Apple. Публичная 1.2 (112) остаётся без изменений. Актуальные условия повторной отправки находятся в [чек-листе](ReleaseGates-1.3.json), исторический чек-лист 154 сохранён отдельно.

## Подтверждено

- Исходная ревизия бинарного файла: `3bcb02f5fff4209fc53da2c80aad462d907cd285`; обязательный [Quality checks 40971877288](https://github.com/Serlest/UkrainianCommunity/actions/runs/40971877288) завершился успешно.
- 62 проверки в iOS Simulator: 55 Swift Testing и 7 XCTest.
- На физическом Mac прошли 19 целевых проверок в Debug и повторно в Release. Для этого использовалась временная локальная схема с компиляцией выбранного набора. Обычный набор iOS CI и утверждения тестов не изменялись. Полный существующий тестовый bundle пока не компилируется на Mac из-за ссылок на simulator-only fixtures; исходный неуспешный запуск сохранён в отчёте.
- Под Serlest Gmail (администратор) в обычном запуске Debug и Release проверены открытие и возврат из 13 разделов профиля. В управлении пользователями отдельно подтверждена загрузка реальных данных. Решения по материалам, сообщения, роли и организации не изменялись. Это проверка указанного сценария падения, а не полная приёмка всех операций и ролей на Mac.
- Архив 155 и подписанный пакет для распространения собраны; строгая проверка подписи прошла, production APNs включены, отладочный доступ выключен, необязательного шифрования нет.
- Все 34 privacy manifests совпадают с архивом 154. Опциональная аналитика не включалась. Перед загрузкой повторно проверены действующие серверные условия согласия.
- Загрузка в Apple завершилась успешно; независимый API read-back подтвердил VALID, APP_STORE_ELIGIBLE и IN_BETA_TESTING для внутренних тестеров. Сохранены заметки на украинском, немецком и английском. Основная установка на Mac обновлена через официальный TestFlight до 155.
- В обеих существующих группах TestFlight доступ с Apple silicon Mac уже включён. В проекте включён Mac destination; схема `UACMac` запускает Release.

## Ещё не подтверждено

- Повторная проверка именно установленной Apple-копии: её процесс пока задерживается на `_dyld_start` до интерфейса приложения. Причина ещё не установлена; запрошен ручной запуск оператором. Локальные Debug/Release-проходы не считаются подтверждением этой копии. Подпись и защитные настройки установленного приложения не изменялись.
- Публичная настройка «Make this app available» для Mac App Store: требуется вход оператора в открытой вкладке Safari. Необратимая отметка полной совместимости Mac по ограниченному набору проверок не выставлялась.
- Сборка 155 обновлена на iPhone без удаления приложения; запуск и восстановление входа пока не проверены: устройство заблокировано. Обход блокировки и изменение способов входа не выполнялись.
- Повторная отправка 1.3 с билдом 155 на рассмотрение Apple возможна только после закрытия текущих открытых условий. Готовность исходного кода, TestFlight и публичный выпуск считаются отдельно.

Точный актуальный статус и артефакты: [отчёт](Verification/MacCompatibility20261030.json).

Свежий read-back метаданных: в черновике App Store выбран 155, все 16 новых изображений остаются COMPLETE с исходными контрольными суммами; повторной отправки на рассмотрение не было.
