# Build 80: сбой удаления аккаунта, 9 сентября 2026

## Подтверждённая причина

В production четыре вызова `deleteOwnAccount` 13:32–13:33 UTC остановились на стадии `references`: Firestore вернул `9 FAILED_PRECONDITION` из-за отсутствующего индекса collection group `dsaStatements`, поле `decision.decidedByUserId`. Профиль к этому времени уже получил `deactivated`/`deletionState=inProgress`; запись Firebase Auth сохранилась. Повторный вход пытался продолжить удаление и попадал в ту же ошибку.

Пробел проверки выпуска: Firestore Emulator не проверяет наличие production-индексов. Успешные локальные сценарии не подтверждали эту облачную зависимость.

## Исправление

- Недостающий индекс добавлен в конфигурацию репозитория и создан в production; сохранены существующие индексы поля. Состояние `READY` подтверждено.
- До деактивации и любых удалений проверяются все запросы удаления. Ошибка зависимости возвращает временную недоступность и оставляет действующий аккаунт без изменений.
- Запись частичного сбоя теперь сохраняет и числовой код ошибки.
- Внутренняя функция обслуживания продолжает только уже запрошенное, прерванное удаление при точном совпадении UID, почты и состояния. Новая публичная функция не создана; проверка недавнего входа публичного callable сохранена.
