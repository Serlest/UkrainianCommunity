# Предложение обновить UAC

Реализация включена в пакет 1.0.2 (66); этапы проверки и распространения описаны отдельно в `Build66TestFlight-2026-09-03.md`. В уже установленном build 65 такого механизма нет: пользователю необходимо сначала получить новый клиентский билд. Ниже сохранены результаты первоначальных локальных проверок.

## Поведение

- Проверяется публичная версия UAC по Apple ID `6772565024`, а не последний загруженный build/TestFlight. Установка ничего не делает автоматически.
- Если совместимая версия новее установленной: локализованное окно DE/UK с «Оновити зараз / Jetzt aktualisieren» и «Пізніше / Später».
- Первая кнопка открывает фиксированную страницу `https://apps.apple.com/app/id6772565024`; URL не берётся из ответа сервера. Обновление выполняет пользователь в App Store.
- «Позже» скрывает окно до следующего открытия, включая возврат из background и новый запуск процесса. Постоянного snooze или «не показывать» нет.
- Возврат непосредственно из App Store после нажатия «Обновить» не вызывает немедленное повторное окно. Следующее обычное открытие снова проверяется, если версия осталась старой.
- Переход только в inactive (Control Center/системное окно) не считается новым открытием.
- Проверка асинхронная, без задержки splash. Ошибка/отсутствие сети не блокирует приложение. Ответ Apple кешируется в памяти до 60 секунд для быстрых повторных открытий, не сохраняется как отказ от напоминания.
- Вход, MFA, обязательные документы, Face ID и уже открытые редакторы/диалоги имеют приоритет. Проверка состояния окна выполняется только пока есть ожидающее предложение и приложение активно; при уходе в фон задача и старый результат отменяются.

## Контракт

Сопоставляются точный App Store ID и bundle ID `at.serlest.UkrainianCommunity`, числовая версия и минимальная iOS. `1.10 > 1.9`, `1.0 == 1.0.0`; некорректные версии не вызывают предложение. Проверка App Store страны использует StoreKit storefront, переводит ISO alpha-3 в alpha-2 через Foundation; выбранная в UAC федеральная земля и язык на неё не влияют. При отсутствии StoreKit storefront используется регион устройства; неизвестный регион пропускается.

Apple получает запрос каталога только с app ID, страной и типом software. Firebase, Rules, IAM и серверные настройки для этой функции не меняются.

Источники API: [Apple ID lookup](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/LookupExamples.html), [параметр country](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/Searching.html), [StoreKit countryCode](https://developer.apple.com/documentation/StoreKit/Storefront/countryCode).
