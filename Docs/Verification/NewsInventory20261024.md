## Зафиксированные проблемы по коду
- Изменение contentVersion (включая лайк/сохранение) меняет referenceDate и запускает сетевую перезагрузку всей browse-ленты.
- После редактирования callback обновляет первую страницу общей модели, не саму старую открытую новость.
- Одинаковые параллельные loadIfNeeded не объединяются.
- Текст статьи окрашен как ссылка (accent), хотя не интерактивен.
- publish проверяет меньший набор ограничений, чем canPublish (метаданные, немецкая версия, расписание).
