# Пункт 9/19 — Довідник и права редакторов

| Группа | Маршруты и проверки |
|---|---|
| Публичный каталог | Главная вкладка → категории/подкатегории → статья → информационные блоки/оглавление → региональные блоки, источники/ссылки/телефон; поиск по uk/de и скрытие; последние добавления/перемещённый или удалённый маршрут; пустота/ошибка/кэш/повтор |
| Данные | DirectoryContentStore → маркер миграции и directoryCategories → полный валидный снимок/дисковый кэш/офлайн; новые ревизии, tombstone, конкурентный listener, восстановление подключения |
| Управление | Категории по трём группам → существующая/новая → название/описание uk/de, символ, группа/порядок/скрытие, подкатегории и статьи; перенос/удаление; предпросмотр перевода |
| Статья | Заголовок/вступление uk/de, перевод с подтверждением, подкатегория/скрытие, блоки/порядок/удаление последнего видимого блока; новая статья и блок; региональный редактор каждой земли; источники и URL |
| Блок | uk/de заголовок/текст, символ/скрытие, источник, телефон, экстренные контакты/перевод; общие и региональные блоки |
| Публикация | Несохранённая форма/отмена/выход; подтверждение/валидация двух языков/источников; saveDirectoryCategory → транзакция revision CAS → ответ → повторное чтение; ошибки/повтор/смена аккаунта/отзыв доступа во время запроса; удаление custom категории отдельным действием |
| Права редакторов | Профиль → доступ к довіднику → действующие/профили отсутствуют/ошибка → кандидаты/поиск/страницы → просмотр полномочий/подтверждение grant/revoke → manageDirectoryEditorAccess → история/запись уведомления; конфликт/идемпотентность/повтор/поздний ответ |
| Роли | Владелец приложения: редактор + управление доступом; назначенный редактор: контент без управления правами; админ приложения/организационные роли/обычный пользователь без отдельного grant: только чтение; ограниченные аккаунты и гость; прямой маршрут и серверные запреты |
| Оформление | Уникальные формы/меню/диалоги/ошибки/загрузка; uk/de, light/dark, обычный/AX текст, клавиатура, возврат и промежуточные переходы |

Исправления проверяются в симуляторе и изолированных Firebase-эмуляторах. Содержательные правки реальных юридических/медицинских статей не входят в аудит интерфейса и не публикуются без проверки прямых официальных источников. Автоматизация публикаций/общая поддержка/баннеры — в своих пунктах; здесь их маршруты и связи. Новая загрузка TestFlight не запрошена.
